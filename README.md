# SyncWatch Frontend

SyncWatch Frontend application built with Next.js 16 App Router, TypeScript, Tailwind CSS v4, Axios, and Socket.IO Client.

## Phase F1 - Foundation & App Shell

Phase F1 establishes the clean, performant frontend architecture and App Shell without implementing future feature business logic.

### Tech Stack
- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Axios
- Socket.IO Client
- Lucide React
- React Context + Custom Hooks

### Getting Started

1. Copy `.env.example` to `.env.local`:
   ```bash
   cp .env.example .env.local
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run dev server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
